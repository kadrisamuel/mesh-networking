  ## Findings

1. HIGH — Known-route custody ACK oracle.
   Unknown-route envelopes skip authentication,
   commit, and receive an ACK; envelopes using a
   known routing tag but invalid ciphertext fail
   authentication before commit/ACK. An attacker
   with an observed routing tag and valid 18-bit PoW
   can therefore probe whether a nearby device
   belongs to that route. This contradicts the
   requirement that unknown tags and authentication
   failures be indistinguishable. Evidence: docs/
   spec/PROTOCOL_V1.md:100, docs/spec/
   PROTOCOL_V1.md:225, docs/spec/
   CRYPTOGRAPHY_V1.md:241.

2. MEDIUM — The 2^24 key-use rollover can deadlock.
   At exactly 2^24 seals, the old outer key cannot
   encrypt another envelope. But the mandatory MLS
   Update is itself an old-epoch MLS message
   requiring that key; wrapping it with the new
   epoch key would fail the required epoch match.
   The protocol must reserve the final old-key seal
   or update earlier. Evidence: docs/spec/
   CRYPTOGRAPHY_V1.md:237, docs/spec/
   TEST_MATRIX.md:104.

3. MEDIUM — The positive OpenMLS fixture violates
   the frozen group-ID profile.
   The harness uses the 29-byte string DEC-001-16-
   member-measurement, while the specification
   requires exactly 32 bytes. Thus the claimed
   7,094-byte “exact” conforming bootstrap
   measurement is not conforming, although the
   8,192-byte class still has ample headroom.
   Evidence: docs/spec/vectors/v1/openmls_harness/
   src/main.rs:208, docs/spec/
   CRYPTOGRAPHY_V1.md:206.

4. MEDIUM — PRO-FRAG-001 remains partly undefined.
   Each exhaustive loss-mask set contains an all-
   fragments-lost case—four cases total. Those cases
   have no “first fragment,” so the required advance
   to 600 seconds after the first fragment and
   assembly expiry cannot be executed as written.
   Prior finding 7 is therefore unresolved.
   Evidence: docs/spec/TEST_MATRIX.md:68, docs/spec/
   TEST_MATRIX.md:83.
